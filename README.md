# Mr. Cook – Taste the Legacy of Rawalpindi! 🍔🍕🍟

A modern, responsive, high-converting fast-food restaurant landing page for **"Mr. Cook"**, located in **Westridge III, Rawalpindi**.

---

## ✨ Features & Layout Structure

1. **Header & Navigation Bar**:
   - **Brand Identity**: Custom fast-food icon badge with "Mr. Cook" typography and location subtitle (*Westridge III • Rawalpindi*).
   - **Navigation Links**: *Home*, *About Us*, *Explore Menu*, *Contact* with dynamic active scrollspy & smooth transitions.
   - **Order Now CTA**: High-visibility glowing pill button triggering a quick-order modal.
   - **Mobile-First Responsive Drawer**: Collapsible menu for mobile and tablet screens.

2. **Hero Section (First View)**:
   - **Atmosphere**: Dark charcoal aesthetic (`#1a1a1a` / `#121212`) enhanced with warm amber lighting (`#d97706` / `#f59e0b`), radial textures, and subtle backdrop glows.
   - **Headline**: *"Mr. Cook: Taste the Legacy of Rawalpindi!"*
   - **Subtext**: *"Authentic flavors, fast service, family joy."*
   - **Primary CTA**: Brightly styled **"EXPLORE MENU"** button with a warm amber-to-orange gradient, glowing drop shadow, and smooth scroll down to the Main Menu section.
   - **Visual Composition**: Multi-layered showcase featuring gourmet double smash burgers, crispy seasoned fries, stone-baked cheesy pizza, and floating feature badges.
   - **Social Proof**: Trust stats highlighting a 4.9/5 rating, 25-minute average Westridge delivery, and 100% Halal fresh meat.

3. **About Section ("Our Story")**:
   - Clean overview card anchored directly below the hero section.
   - Includes the exact signature motto:
     > *"Serving the best fast food and traditional flavors in Westridge since 2016. Quality is our promise."*
   - Highlights handcrafted brioche buns, secret Rawalpindi spice blends, and express delivery.

4. **Interactive Main Menu Section**:
   - Filter tabs for *All Items*, *Smash Burgers*, *Cheesy Pizzas*, *Crispy Broast & Wings*, and *Loaded Fries*.
   - Menu items with prices in PKR, descriptions, and one-click "Add to Order" actions.

5. **Location & Contact**:
   - Address details for Westridge III, Peshawar Road, Rawalpindi Cantt.
   - Opening hours (including late-night hours).
   - Direct phone & instant WhatsApp ordering flow.

## 🚀 How to Run

### Option 1: Open Directly in Any Browser
Double-click [index.html](index.html) to open the page directly in Chrome, Edge, Firefox, or Safari.

### Option 2: Run with Local Server (Node.js)
```bash
npm start
```
Then navigate to `http://localhost:3000` in your web browser.
